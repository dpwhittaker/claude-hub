# SPEC

## §G GOAL

one page over everything under `~/projects` — sessions (agents in tmux), services (systemd units + their sites), files — as tabs in free-form panels, per profile, on any device over the tailnet; plus the path-routed reverse proxy in front of each project's dev server.

## §C CONSTRAINTS

- Node ≥ 22 (marked v18 ESM-only). single process, no framework, no build step (v2/ is classic scripts; CodeMirror from esm.sh at runtime w/ a textarea fallback).
- bind `127.0.0.1` only. external reach via Tailscale (see `.claude/skills/tailscale/`).
- deps locked: `http-proxy ^1.18.1`, `marked ^18.0.3`. CommonJS. (⊥ `ws` — gone w/ the v1 file watcher, T106.)
- projects root = `~/projects` (env `PROJECTS_ROOT` overrides); hub state = `~/.claude-hub` (env `HUB_STATE_DIR`), ∉ the root.
- proxy port 8002 (env `PROXY_PORT` overrides).
- ttyd unix sockets only — no TCP. socket dir = `/run/ttyd/`, owner=david, mode `0755` (systemd `RuntimeDirectory=ttyd`). ONE ttyd unit (`ttyd-hub.service`, `--url-arg`) for every session.
- claude binary = env `CLAUDE_BIN` else `~/.local/bin/claude`; `claude -p` (titler, completion) rides the user's own login, always `--tools ""`.
- systemd-managed. units in `services/`. `RuntimeDirectoryPreserve=yes` + `KillMode=process` required on the ttyd unit.
- `npm` in PATH at hub runtime (vite scaffold + per-project install).
- Claude Code's own records are read, never written: `~/.claude/sessions/<pid>.json` (registry), `~/.claude/projects/<enc>/<uuid>.jsonl` + `<uuid>/custom-title.json` (transcripts).

(⊥ `GET` cards, ⊥ `DELETE /api/projects/<name>` — T106.)
- the "+ repo" dialog (`v2/tab-home.js` `newRepoDialog`): Name → GitHub (Skip default | Create | Clone | Onboard) → Template radios (Vite default … None last) + Firebase checkbox (disabled iff template ∈ {none, jekyll}); template fieldset hidden for clone/onboard.
- `GET /api/gh/repos` → `{repos: [{nameWithOwner, description, isFork, isPrivate, updatedAt}]}`. sort: non-forks first then forks; within each group `updatedAt` desc. 503 on `gh` failure. cached in-process, 10 min TTL. response excludes candidates whose basename matches an existing folder under `PROJECTS_ROOT`.
- `GET /api/projects/orphans` → `{folders: [string]}`. dirs under `PROJECTS_ROOT` that exist but lack `.project-meta.json` and don't start with `.`.
- `POST /api/upload-anywhere` multipart `{path, filename?, file}` `?overwrite=1` → `{ok, path, size}`; `path` ! ≥ 1 segment (⊥ the root itself).
- `GET /term/hub/?arg=<id>` → proxy to `unix:/run/ttyd/hub.sock` (HTTP + WS upgrade); ttyd runs `ttyd-attach-hub.sh <id>`. the five mobile shims are spliced into every `/term/<key>/` index (V40, V61–V64). `/term/wsl/` 301s to `/term/shell/` (legacy bookmark; nothing serves it now).
- `GET|*  /<proj>/*` → reverse-proxy if `.project-meta.json` declares `proxyTarget`
- PWA static assets from `assets/` via `/assets/<file>` (`^[A-Za-z0-9._-]+$`, `public, max-age=86400`) + root aliases `GET /sw.js`, `GET /manifest.webmanifest` (`no-cache`), `GET /favicon.ico|/favicon.png`, `GET /apple-touch-icon[-precomposed].png`. sw MUST stay at root scope.
- `GET /api/term-capture/<key>` → `{key, cols, rows, lines: string[], pending: {id, kind, payload, createdAt}|null, state: {lastMessage?, lastMessageAt?, notification?, notificationAt?}|null}`. `tmux capture-pane -p -J -t =<key>:` of the VISIBLE pane (V76). polling it = "watching" the key (V75). 400 bad key (V74), 404 no such tmux session. every `/api/term-*` key passes `canonicalTermKey` first: `<proj>__hub-<id>` → `hub-<id>` (V97).
- `POST /api/term-input/<key>` body `{text: string ≤ 8192, enter?: bool}` → `{ok: true}`. `tmux send-keys -l -- <text>` then `Enter` iff `enter`.
- `POST /api/term-scroll/<key>` body `{lines: int}` → `{ok: true, ticks}`. SGR wheel ticks typed into the pane, negative = older (V77), ≤ 200.
- `POST /api/term-pending/<key>` (from `services/glasses-relay-hook.mjs`) body `{kind ∈ question|permission|stop|notification, session_id?, payload}` → `{ok, relay: bool, answer?, reason?}`. `question`/`permission` are HELD (long-poll) until answered/released/watcher lapses/540 s; unwatched → immediate `relay:false` (V75). `stop`/`notification` → recorded into `state`, immediate.
- `GET /api/term-pending/<key>` → `{pending, state}`.
- `POST /api/term-pending/<key>/answer` body `{id, answer: object}` | `{id, release: true}` → `{ok: true}`; 404 nothing pending, 409 stale id.
- `POST /api/stt` body = raw PCM (`audio/L16; rate=16000`, s16le mono) or any container faster-whisper decodes → proxied to `STT_URL/transcribe` → `{text, seconds, ms, device}`. 503 `stt unavailable` when the unit is down (V78).
